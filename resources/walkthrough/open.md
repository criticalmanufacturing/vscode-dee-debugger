# Browse and open actions

The **DEE Explorer** lists every action the MES reports, grouped by extension point
(`MaterialManagement.MaterialManagementOrchestration.TrackInMaterials.Post` → nested folders). Group rows show how
many actions they hold.

Click an action to download it as `<ActionName>.cs` into your DEEs folder (auto-detected:
`Cmf.Custom.Data/DEEs`) and open it with full C# IntelliSense.

Only the code **between the four marker comments** belongs to you — the wrapper is generated by
the host. Save with **Ctrl+S** for a local copy; **Save Action to MES (Compile & Save)** publishes
it. Compile errors land in the Problems panel on the right lines.

Badges on a row tell you what needs attention: `DEBUG`, `pending upload`,
`not effective (Active)` (a draft: it runs while no version is effective, but a version
staged later would take over — use **Make Version Effective**),
`disabled`, and the version.
